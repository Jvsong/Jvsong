# Hi, I’m Jv.

I test mobile apps, APIs, and connected devices. One of my favorite tests is a walk around the block with a GPS tracker and a running watch. Back at my desk, I compare the two routes to see where they start to drift.

### Selected projects

[**Runalyzer**](https://github.com/Jvsong/Runalyzer---) · A training log for curious runners. Plot pace, heart rate, and elevation from a Garmin file on the same timeline.

[**E-commerce test suite**](https://github.com/Jvsong/graduation-project) · Automated checks for an online store, from a login smoke test to a full regression run. Screenshots and reports help trace failures.

[**ShopPilot Admin**](https://github.com/Jvsong/-ShopPilot-Admin-) · A store management app built with Spring Boot and Vue. Follow a product or an order from the admin screen down to the database.
